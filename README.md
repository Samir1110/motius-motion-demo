# Motius Motion Demo

Static interactive demo for text-to-motion, motion-to-text, structural motion tasks, and motion editing.

The Text-to-Motion section compares Motius (1.7B), HY-Motion 1B, and MotionMillion 3B on manually written OOD prompts. Motion meshes are precomputed and included in this repository; the deployed site does not need a Python backend or model runtime.

Open `index.html` through an HTTP server for local preview.
